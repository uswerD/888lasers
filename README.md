# 888 Lasers

Минималистичный сайт услуг изготовления в Челябинске.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

## Render

Добавь Environment Variable:

`TELEGRAM_URL=https://t.me/USERNAME`

где `USERNAME` — username Telegram-бота без `@`.

Сайт не собирает имя, телефон и другие контактные данные через форму: заявка уходит в Telegram.
