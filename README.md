# 888 Lasers — v1

Первый рабочий прототип сайта 888lasers.ru.

## Что уже работает

- адаптивный лендинг;
- услуги лазерной резки, гравировки и 3D-печати;
- форма заявки;
- загрузка файла;
- сохранение заявок в SQLite;
- выдача номера заявки;
- подготовка под Render.

## Запуск локально

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:5000
